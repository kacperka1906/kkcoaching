# JD Gyms QR route

Public QR URL to print on physical JD Gyms Cwmbran materials:

`https://kkcoaching.fit/jd/`

`/jd/` is a real, non-indexable campaign landing page generated by `src/pages/jd.astro`. It should return HTTP 200. It offers links to Personal Training, Hybrid Coaching, Online Coaching and the contact page. Its WhatsApp link includes a message explaining that the visitor scanned the JD Gyms banner.

The current service links have no UTM query parameters. Campaign attribution should be assessed separately before changing the printed URL or adding tracking.

Keep the printed URL stable. Do not add a redirect over this landing page; `netlify.toml` documents the current routing and adds an `X-Robots-Tag` header.

Do not add `/jd/` to the sitemap. It is a campaign/vanity URL, not an indexable landing page.
